# Task 04 — 产品、项目、里程碑与任务

## Codex 指令
实现 Product、ProductVersion、Project（product_rd/custom_delivery）、Milestone、WorkItem 和需求关联。先完成列表/详情/表单/任务状态流转和负责人分配，再实现简单任务看板。正式产品项目支持预设 PLM 阶段：立项、输入、方案、β、Release、定型；客户定制项目可用自定义里程碑。禁止把 PLM 系统文件归档功能整体重做。任务可以独立存在也可归属项目。

## 验收标准
- [ ] 一个产品有多个版本；项目类型可区分。
- [ ] 项目负责人设置里程碑与计划/实际日期。
- [ ] 任务分配、优先级、截止时间、阻塞/完成状态受控。
- [ ] 任务与需求关联，可从两个方向互查。
- [ ] 能查询到超期任务，修改截止日期仍保留历史。
- [ ] 禁止越权修改其他项目任务。
