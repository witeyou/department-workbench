# Task 01 — 市场客户与询盘 V0.1

## Codex 指令
阅读 `AGENTS.md`、业务范围、流程、模型、权限矩阵及本任务。实现 Customer、Contact、Inquiry、FollowUp 的最小完整业务闭环（模型、迁移、Service、表单、列表、详情、添加/编辑、筛选、分页、导航、权限、审计、测试）。不要开发商机复杂销售预测、技术评估和 AI。业务编号采用并发安全方案。对于商机可以先保留后续任务计划，不强行同时实现。遵守对象权限：市场人员只能编辑授权记录；负责人可见组内。所有状态与负责人变更有历史。

## 页面路径（建议）
`/market/customers/`、`/market/inquiries/`、`/market/inquiries/<id>/`；使用 name URL 而非在模板硬编码路径。

## 验收标准
- [ ] 市场人员创建客户、联系人、询盘，能更新跟进记录与下次跟进日期。
- [ ] 询盘编号唯一；搜索/状态/负责人筛选及分页可用。
- [ ] 详情显示归属人、来源、历史、跟进记录。
- [ ] 关闭询盘必须填写原因；跨组访问受限。
- [ ] 管理员可维护基础数据，界面没有假指标。
- [ ] 有模型、服务、视图和权限测试。

## 不做
跨系统同步、商机销售预测、移动 App、复杂权限配置界面。
