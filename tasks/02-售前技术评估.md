# Task 02 — 市场→研发技术评估

## Codex 指令
先阅读工程规则、业务流程、数据模型和权限矩阵。开发 TechnicalReview 模型及市场/研发双角色操作流程：市场对询盘提交申请，研发负责人指派评估人，评估人填写建议并答复，市场确认已收到；允许资料补充和取消未开始请求。每次关键变更记录动作日志，关联原询盘，记录答复截止时间与超期。禁止把评估答复自动变成正式产品需求或交付承诺。请以 service 层定义状态机、事务和对象级权限，并提供完整测试。

## 验收标准
- [ ] 市场可从询盘详情发起评估请求并跟踪状态。
- [ ] 研发负责人可指派，普通研发人员仅能处理本人任务。
- [ ] 缺少信息可退回补充；超期逻辑有测试。
- [ ] 评估结果可见于原询盘，市场确认回执。
- [ ] 所有操作生成审计，非法流转拒绝且数据不被改变。
- [ ] 可以用至少三种角色演示完整流程。
