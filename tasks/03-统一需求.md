# Task 03 — 统一需求中心

## Codex 指令
实现 Requirement 及来源关联（询盘 N↔M 需求）、关联技术评估、需求评审状态机、决策记录和审批限制。允许客户不同询盘映射同一共性产品需求。状态参考 `docs/02-业务流程.md`。正式接受/拒绝/暂缓只有具备相应权限的角色可操作，必须填写理由，记录历史。列表按状态、产品、优先级、负责人筛选。不要在本任务完成项目甘特图或 Dify。

## 验收标准
- [ ] 多询盘可关联同一需求，关联关系记录来源。
- [ ] 需求含业务描述、验收标准、优先级、业务/技术负责人。
- [ ] 审批合法流转，决策结果记录人/时间/理由。
- [ ] 无权用户无法调整优先级或批准需求。
- [ ] 原始询盘和评估历史始终可追溯。
