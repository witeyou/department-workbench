# Task 05 — 部门管理驾驶舱

## Codex 指令
基于已完成的业务表，开发领导驾驶舱和角色工作首页。指标必须由 Django ORM 按对象权限聚合：本月新增询盘、待研发评估/超期、在研项目、里程碑临期、超期任务、阻塞任务与待决策需求。指标卡点击下钻到受同样权限约束的明细列表。优先原生统计和简单图表；不要使用虚构数据，也不要让 AI 参与原始数值计算。

## 验收标准
- [ ] 每个指标有一致的名称、口径、日期边界。
- [ ] 空数据时显示 0/暂无记录，而非随机演示数据。
- [ ] 列表/统计严格一致；领导与普通人员权限差异正确。
- [ ] 统计卡可下钻到可核查记录。
- [ ] 测试边界日期、跨年、超期及授权过滤。
