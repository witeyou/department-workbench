# Task 00 — 基础工程验收

## Codex 指令（复制这段或让 Codex 读取本任务文件）
先阅读 `AGENTS.md`、`docs/START_HERE.md`、`docs/01-产品范围.md`、`docs/06-技术架构.md` 和本文件。验证当前 Django 工程并修复启动缺陷，不要开发业务 CRUD。保持 Python3.12/Django5.2/uv 架构。运行依赖安装、migrate、check、ruff、pytest、makemigrations --check，必要时更新 lockfile。检查 Docker Compose 配置逻辑但不得假称已在无法运行 Docker 的环境验证。完成后更新 development-plan.md 和提交建议。

## 允许修改
settings、urls、accounts、dashboard、templates、static、deploy、tests、README、基础配置。

## 验收标准
- [ ] `uv sync --dev` 成功，锁文件生成并跟踪。
- [ ] `uv run python manage.py migrate` 成功。
- [ ] 未登录不能访问首页；登录后可访问，退出有效。
- [ ] 可以创建管理员；角色档案可通过 Admin 设置。
- [ ] `uv run python manage.py check` 无错误。
- [ ] `uv run ruff check .` 和 `uv run pytest -q` 通过。
- [ ] Django 模型与迁移一致。
- [ ] 不泄露环境密钥，无真实业务指标伪造。
