# Task 02B — 市场商机与商务跟进

## Codex 指令
阅读业务流程、数据模型、权限矩阵和已完成的客户/询盘模块，实现轻量 Opportunity 商机管理：关联客户及来源询盘、商机阶段、预计金额、预计成交时间、负责人、跟进活动和下次跟进时间。提供列表、筛选、详情、创建/编辑、阶段流转与原因记录。金额、联系人和商务备注按角色与业务归属实行最小权限。商机不是需求、正式合同或已经批准的定制项目；不要自动生成项目或任务。不要开发复杂销售预测和报价财务系统。

## 验收标准
- [ ] 一个客户可以拥有多个商机，商机与相关询盘可追踪。
- [ ] 支持按阶段、负责人、客户和预计成交日期筛选。
- [ ] 预计金额按权限隐藏，普通研发成员不能查看未授权商业字段。
- [ ] 跟进记录和阶段变更历史可核查。
- [ ] 超期未跟进商机能够被查询并用于驾驶舱。
- [ ] 模型、权限、业务操作均有测试。

## 建议顺序
技术评估闭环完成后推进本模块，与统一需求中心可并行，但不要同时让不同 Codex 任务修改同一数据库迁移。
