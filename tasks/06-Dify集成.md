# Task 06 — Dify AI 能力嵌入

## Codex 指令
先读 `docs/08-AI集成契约.md`。在询盘详情增加「AI 分析询盘」按钮：Django 调用固定 Dify Workflow API，检查对象授权、设置超时、校验 JSON schema，保存 AIJob 和 AIResult 草稿。用户可编辑/拒绝/确认草稿，正式写入只能通过业务 service。Dify 不可用时已有市场/研发操作必须正常。使用 mock/stub 完成自动测试，不让 CI 依赖联网或真实 API Key。不要接入模型直连 SQL 和任意外部网络工具。

## 验收标准
- [ ] 没有 Dify 配置时显示「AI 暂不可用」，基础业务正常。
- [ ] 模型请求不含不必要的个人信息和商业机密。
- [ ] 输出字段严格校验，不接受任意无结构回答。
- [ ] 草稿未确认前不更改原记录；人工操作留痕。
- [ ] 超时、失败、重复提交、越权调用均有测试。
