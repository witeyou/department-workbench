# 10 业务术语

| 术语 | 定义 | 不等同于 |
|---|---|---|
| 客户 Customer | 企业或组织档案 | 单个联系人 |
| 询盘 Inquiry | 客户发来的咨询、询价、技术诉求的一次记录 | 已确认商机、研发需求 |
| 商机 Opportunity | 有潜在商务成交目标的事项 | 询盘、正式合同 |
| 技术评估 TechnicalReview | 市场请求研发给出技术可行性与建议的内部协同任务 | 研发承诺、正式立项 |
| 需求 Requirement | 可评审、可规划、可验收的功能或业务诉求 | 每一条原始客户消息 |
| 产品 Product | 持续演进的软件/系统产品 | 某一版本 |
| 版本 ProductVersion | 产品的某次规划或发布 | 某个客户定制项目 |
| 项目 Project | 有负责人、目标、起止范围的交付组织单元 | 单一任务 |
| 任务 WorkItem | 可被负责人执行并确认完成的工作单元 | 完整项目 |
| 里程碑 Milestone | 可检查的时间节点或阶段成果 | 单纯日期字段 |
| 审计 AuditLog | 谁在何时对什么做了何种修改 | 普通评论或系统错误日志 |
| AI 草稿 AIResult | 模型辅助生成的待人工审核建议 | 正式业务记录 |
