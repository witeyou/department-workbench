# 端到端示例：电能质量监测系统客户需求

**以下均为虚构测试数据，只用于开发演示。**

1. 市场录入客户「华东示例电力公司」，新建询盘：需要 40 台监测装置与主站软件，支持 IEC 61850，要求专项统计分析。
2. 询盘 `INQ-2026-0001` 关联产品方向「电能质量在线监测」，需要确认统计周期、是否重新计算历史数据、报表格式。
3. 市场创建 `TR-2026-0001` 技术评估，研发负责人指派评估人员。
4. 研发答复：通信方式已有支持，专项统计为待评估定制项；要求市场补充样例报告和验收标准。
5. 市场补充资料，研发给出最终建议；该建议不构成正式研发承诺。
6. 产品负责人批准创建需求 `REQ-2026-0001`，关联两个类似询盘（模拟共性需求）。
7. 若转客户定制，创建 `PRJ-2026-0001`，规划里程碑、开发任务与测试任务；若纳入标准产品，绑定产品版本。
8. 领导驾驶舱显示正在评估需求、技术响应超期、项目里程碑和阻塞任务；点击能查看原记录。
9. Dify 可以生成询盘结构化草稿和缺失问题建议，但不得直接批准需求或修改项目日期。
