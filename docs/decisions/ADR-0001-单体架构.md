# ADR-0001 采用 Django 单体 + 独立 Dify

- 状态：已接受（启动工程）
- 背景：20–30 人部门内网使用；市场与研发流程高度定制；Codex 辅助开发；现有 Python/Ubuntu/GitLab 技术基础。
- 决策：以 Django 单体承载业务事实、流程与权限，PostgreSQL 存储；Templates + HTMX 交互；Dify 提供可选 AI 工作流，独立服务；不引入通用 CRM、项目系统，也暂不采用 Vue + FastAPI 前后端分离。
- 优势：减少项目数量、API 联调、权限重复实现和初期部署负担；更快实现一个真实闭环。
- 代价：复杂实时协作与高交互甘特图在后续扩展时可能需要前端架构调整；单体代码必须遵守清晰模块边界。
- 触发重评估条件：出现复杂实时协作或移动端独立客户端、前端显著超过传统表单/看板能力、跨部门多租户或系统规模跃升。
